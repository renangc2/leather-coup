# 皮衣之下 · LEATHER COUP

一个关于英伟达董事会的虚构讽刺小游戏。你是董事会里坐在最边上的那个人，今晚你决定让那个穿皮衣的人离开。

- 纯前端、无框架：**双击 `index.html` 就能玩**
- 8 个季度一局，约 5–7 分钟，6 个结局
- 赛博霓虹 + 真人表情包：老黄会根据局面换表情、换字幕
- 带 CRT 扫描线、合成音效和结局图鉴（localStorage 存档）

## 玩法

每季度从 7 张行动卡里选 1 张，老黄会反击一手，然后你选择怎么接。8 个季度后召开年度股东大会表决。

| 指标 | 说明 |
| --- | --- |
| **支持率** | 拉到罢免门槛以上就赢。开局 24，门槛 60（随股价在 52/60/66 之间浮动） |
| **股价** | ≥130 时董事不敢动，门槛升到 66；≤85 时业绩难看，门槛降到 52；跌破 50 直接崩盘 |
| **现金** | 行动要花钱，每季度到账 +10 |
| **黑料** | 放出黑料是涨支持最快的方式；终局握着 ≥3 份还能额外 +8% |
| **老黄警觉** | 行动会让他起疑，每季度还会因为你的存在感自然上涨；到 100 他先动手，你被保安请走 |

### 两个互动环节

- **点他的照片**：每季度可以当众怼他一次，`+1 支持、+4 警觉`，他会换表情回你一句。
- **反应条**：他每次出完牌，你可以选
  - 👏 鼓掌：警觉 −6
  - 🙄 翻白眼：支持 +2、警觉 +5
  - 🖐 拍桌：支持 +4、警觉 +10、股价 −3

小技巧：

- 支持率领先门槛 12 个点以上（第 3–7 季度），可以点「发起临时股东会」提前摊牌，触发另一个结局。
- 「向老黄表忠心」免费，能压 28 点警觉，但会掉支持率、浪费一个季度。
- 「许诺 CEO 之位」最多用两次，第二次效果减半——因为另一位董事已经听说了。
- 表情包字幕会跟着他的招数变，比如「卖到月球了」「审计，明早九点」。

## 数值与平衡

数值用脚本跑了模拟校准：会玩的人胜率约 55–65%，无脑重复「串联董事」约 30%，随机乱点约 5–10%。失败主要来自警觉失控和股价崩盘，而不是运气。

## 技术说明

- `index.html` 内含全部 HTML / CSS / JS；照片在 `assets/` 下，共 4 张，约 260 KB
- 照片按 4:5 裁切，用 `object-fit: cover` 适配不同屏幕；底部叠加带黑描边的梗图字幕
- 标题页保留 16×16 像素画，游戏内使用真人照片作为「表情包」
- 音效由 WebAudio 实时合成，右上角 `♪` 可静音
- 结局图鉴存在 `localStorage`，键名 `leather-coup-endings-v1`
